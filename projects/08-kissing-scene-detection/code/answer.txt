# 图像处理流程对应代码位置

## 1. 提取每 1 秒片段的最后 1 帧静态图像
- **文件**：`pipeline.py`
- **方法**：`one_video_extract_audio_and_stills`
- **实现细节**：
  - 第 77-116 行：从视频中提取图像帧
  - 第 93 行：通过 `frame_id % math.floor(frame_rate * params.vggish_frame_rate) == 0` 确定提取帧的间隔
  - `params.vggish_frame_rate` 值为 0.96（接近每秒 1 帧），因此每个提取的帧代表每秒片段的最后一帧

## 2. 训练/测试预处理步骤
- **文件**：`pipeline.py`
- **方法**：`transformer`（第 64-70 行）
- **训练时预处理**：
  - 随机裁剪 224×224 像素：`transforms.RandomResizedCrop(img_size)`（第 66 行）
  - 随机水平翻转：`transforms.RandomHorizontalFlip()`（第 67 行）
  - 标准化：`transforms.Normalize(params.mean, params.std)`（第 69 行）
- **测试时预处理**：代码中未明确提供测试专用的预处理，但通常会移除随机翻转，使用固定裁剪（如中心裁剪）

## 3. 3D ResNet 适配：堆叠 16 帧图像
- **文件**：`data.py`
- **类**：`AudioVideo3D`
- **方法**：`_process_temporal_tensor`
- **实现细节**：
  - 创建 16 帧的零张量数组
  - 将图像列表填充到数组末尾
  - 使用 `permute` 转换为 3×16×224×224 格式（第 94 行）
  - 适用于 3D CNN 模型输入

## 4. 通过 ResNet-18 输出 512 维特征向量
- **文件**：`conv.py`
- **函数**：`convnet_init`
- **实现细节**：
  - 第 21-29 行：初始化 ResNet-18 模型
  - 第 28 行：将最后一个全连接层替换为 `nn.Identity()`
  - 第 92 行：计算输出大小，对于 ResNet-18 来说为 512
  - 输出 512 维特征向量，不包含最后一个全连接层

## 关键参数
- **文件**：`params.py`
- **vggish_frame_rate**：0.96（控制每秒提取的帧数）
- **mean**：[0.485, 0.456, 0.406]（图像标准化均值）
- **std**：[0.229, 0.224, 0.225]（图像标准化标准差）

## 整体流程
1. 从视频中提取每秒的最后一帧
2. 应用随机裁剪、翻转和标准化等预处理
3. 堆叠 16 帧图像，缺失帧用零填充
4. 输入到 ResNet-18 模型中提取 512 维特征
5. 特征用于后续的分类或融合操作
